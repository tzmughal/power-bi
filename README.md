# Power BI Enterprise Dashboards & Data Models

[![Power BI](https://img.shields.io/badge/Power%20BI-Enterprise%20BI-F2C811?style=for-the-badge&logo=powerbi&logoColor=black)](https://powerbi.microsoft.com/)
[![DAX](https://img.shields.io/badge/DAX-Data%20Analysis%20Expressions-0078D4?style=for-the-badge)](https://learn.microsoft.com/en-us/dax/)

A portfolio collection of enterprise Power BI analytics models, DAX measures, and data visual dashboards focusing on capital project management, water production, revenue billing, and regional infrastructure metrics.

---

## 📊 Analytics Coverage & Models

1. **Capital Projects Tracking:** Capital expenditure, project completion timelines, budget variances.
2. **Revenue Billing & Financial Modeling:** Billing reconciliation, revenue by tier, customer segment analysis.
3. **Water Production Analytics:** Resource tracking, production metrics, and utility performance.
